# 消毒柜公司成品排版规律报告

## 当前结论

本批已扫描 56 张 PNG，全部为竖版。解析器从人工彩色描边中提出 343 个候选区域：

- 红色 `layout_block`：110
- 蓝色 `product_image`：125
- 绿色 `main_text`：108

当前状态为 `not_ready`。56 张均为“带框标注图”，目录内没有找到一一对应的无标注原成品图，因此不能把标注描边图直接发送给视觉模型当作正式业务成品，也不能据此宣称系统已经学会排版规律。

## 证据边界

- 只有 `source_type=company_published` 且经人工 `verified` 的标注才进入规律统计。
- `pending_review`、外部参考、被拒方案和模型自身预测均不作为正式规律证据。
- 导入和颜色解析不会自动验证蓝图，不会设置黄金项目。
- holdout 数据不得进入 few-shot 示例。

## 扫描质量

- 格式：PNG 56 张。
- 方向：portrait 56 张。
- 常见尺寸：957×1280（28 张）、960×1280（8 张）、959×1280（5 张），另有少量相近尺寸。
- 原图配对：0；仅标注图：56。
- 每张记录均带有 `unannotated_original_not_found` 警告，等待补充无描边原图。

## 下一步人工动作

1. 打开 `/annotation-learning/disinfection-cabinet`。
2. 对照左侧标注图与右侧结构框架，修正漏框、错框和边界。
3. 填写项目归属、页面角色和审核人。
4. 由设计负责人逐张确认；确认后才进入 calibration/holdout。
5. 至少形成 3–5 条已验证 calibration 证据，并有独立 holdout 后，再运行自动拆解评估。

机器可读的逐图扫描结果位于 `backend/evaluation/disinfection_cabinet_layout_report.json`。
