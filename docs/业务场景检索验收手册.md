# 业务场景检索验收手册

> P3.1 规则：Ground Truth 必须在验收检索前定义并冻结。搜索后反馈不再作为验收真值，也不得按返回排名反推相关性。

## P3.1 标准流程

1. 建立数据集版本，将真实需求分为 `calibration` 与 `holdout`。
2. 由业务/设计审核人预先标注案例和模式的 `relevant`、`partially_relevant`、`irrelevant`，记录理由和明确禁用项。
3. 调用 `POST /api/layout-search/ground-truth/freeze` 冻结版本。冻结后禁止修改；修订必须新建版本。
4. 调用 `POST /api/layout-search/evaluation/run`。系统只采用冻结后生成的检索运行。
5. 在 `/layout-search/evaluation` 检查校准集、留出集、总体及逐需求结果。

留出集门禁：案例直接 P@5 ≥ 0.60、案例有用 P@10 ≥ 0.60、模式直接 P@3 ≥ 0.67、禁用模块违规为 0、证据可追溯率 100%，且每个需求至少返回 10 个案例和 3 个模式。`partially_relevant` 的分级相关得分为 0.5，但不计入直接 Precision。

若没有冻结的真实业务数据，页面和 API 必须显示“尚未完成真实业务验收”。自动 fixture 仅验证工程链路，不代表真实业务验收通过。

## 验收包

- 导出：`python scripts/export_layout_search_acceptance.py <版本> <文件>`
- 导入校验：`python scripts/import_layout_search_acceptance.py <文件>`（默认 dry-run）
- 确认写入：追加 `--execute`

验收包不包含图片；导入会校验需求/结果 ID、冻结状态和版本冲突，绝不覆盖已有版本。私密验收文件应放入 `backend/acceptance_data/`。

本手册用于 P3 真实业务验收。自动 Fixture 通过只证明规则和数据链路正确，
不能代替公司真实素材验收。

## 1. 选择 50 张真实素材

从公司已发布且版权、来源明确的成片中抽取 50 张。覆盖主要产品品类、渠道、
内容目的、画布比例和信息密度，避免全部来自同一活动或同一模板。

## 2. 确认蓝图

逐张检查最新 LayoutBlueprint 的画布、方向、模块类型、模块数量、坐标和阅读
动线。修订后由设计负责人将正确版本标记为 `verified`。未确认蓝图不能作为
正式案例检索证据。

## 3. 确认排版模式

在排版模式库执行候选发现，检查来源案例、相似度、必需/可选模块和平均骨架。
只确认结构稳定、适用边界清楚且证据充分的模式；错误模式应停用而不是删除。

## 4. 准备 10 条真实业务需求

使用近期真实 Brief，填写产品品类、渠道、内容目的、投放阶段、目标、受众、
画布、密度及必需/禁止模块。没有明确要求的字段保持为空，不为测试补造条件。

## 5. 提前标记正确参考

检索前由不参与算法开发的设计负责人，为每条需求记录正确模式和正确案例清单，
包括“相关”和“部分相关”的判断标准。该清单不得根据检索排序事后修改。

## 6. 执行检索

打开需求详情并点击“查找排版参考”。若有参考图，确认分析模式、模型名称、
Prompt 版本和失败原因；参考图失败时仍继续检查文本与结构化条件结果。

## 7. 标记相关性

逐条查看 Top10 模式和案例，填写反馈人，然后标记：

- `相关`：可直接作为该需求的主要结构参考。
- `部分相关`：局部结构可复用，但需要明确适配。
- `不相关`：业务、硬约束或结构不适合。

反馈仅用于检索质量评估，不写入 PreferenceEvent，不形成公司偏好权重。

## 8. 查看 Precision

访问 `/api/layout-search/evaluation`，检查已评估需求/结果数、
Precision@5、Precision@10、禁止模块违规数和平均耗时。验收目标为：

- Precision@5 ≥ 0.60。
- Precision@10 ≥ 0.60。
- 禁止模块违规数为 0。
- 结果证据可追溯率为 100%。
- 每个正常结果都有完整 `score_breakdown`。

## 9. 调整权重

先按错误类型分类：业务场景、必需模块、画布结构、密度、风格或确认可信度。
只调整对应规则常量，并使用同一批冻结需求重新检索；不得使用 PreferenceEvent
或事后修改正确答案来提高指标。

## 10. 不能通过验收的情况

- 使用模拟素材冒充 50 张真实公司素材。
- 蓝图或模式未由设计负责人确认。
- 禁止模块结果进入正常推荐。
- 分项分数之和不等于总分，或理由无法追溯到真实字段。
- 参考图分析创建公共 Case 或污染素材库。
- Precision@5 或 Precision@10 低于 0.60。
- 只展示总体指标而无法查看具体运行、结果和人工反馈。
