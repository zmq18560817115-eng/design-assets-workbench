# 公司素材库训练运营手册

## 目标

素材仓库不是单纯存图，而是把“公司真实做过什么、哪些方法值得继续、哪些问题必须避免、什么结果最终被业务采用”沉淀成可追溯的公司设计知识，并让设计服务按业务线调用这些知识。

## 当前系统中的证据等级

1. 公司成品：证明历史上真实制作过，但不自动代表未来仍应延续。
2. 模型拆解：把图片转换为版式、风格、色彩和实拍信息，仍需人工核对。
3. 人工确认：设计负责人确认拆解正确，并填写延续项、避坑项。
4. 公司推荐：设计总监或业务负责人确认它可作为同品类标准。
5. 真实采用：设计服务生成的方向被真实项目采用，是最高价值反馈。

禁止把“已上传”或“已被模型分析”等同于“已训练完成”。

## 五条业务线的最低训练门槛

每条业务线独立达标，不能用其他业务线的样本补足：

| 门槛 | 最低数量 | 验收人 |
| --- | ---: | --- |
| 代表性公司成品 | 10 张 | 素材管理员 |
| 火山视觉模型深度拆解 | 3 张 | AI 运营 |
| 人工确认模型样本 | 3 张 | 设计负责人 |
| 公司推荐黄金样本 | 1 张 | 设计总监 / 业务负责人 |
| 真实业务方向生成 | 5 次 | 需求发起人 / 设计师 |
| 确认被业务采用 | 2 次 | 业务负责人 |

系统中的服务范围：

- 未完成 3 张人工确认与 1 张公司推荐：仅供方向参考。
- 已完成确认和推荐，尚未积累真实采用：业务试运行。
- 同时完成 5 次真实生成与 2 次采用：可正式使用。

## 每周执行流程

### 周一：素材整理

- 每条业务线补充本周新上线、表现好或具有代表性的成品。
- 上传时填写业务线、素材类别、渠道、营销阶段和业务目标。
- 同一套设计的微小尺寸变体只保留代表版本。

### 周二：模型拆解

- 优先选择差异明显的样本，不连续分析高度相似图片。
- 排版类重点检查信息层级、对齐、栅格和留白。
- 风格类重点检查视觉语言、情绪、质感和元素组合。
- 色彩类重点检查主辅色、对比关系和使用比例。
- 实拍类重点检查场景、光线、构图、人物和产品摆放。

### 周三：人工校正

- 设计负责人从训练台打开系统推荐的优先审核案例。
- 对照原图核对模型拆解，不准确时先编辑再确认。
- 每张样本必须写清“希望延续的方法”和“应避免的问题”。
- 规则必须描述可执行方法，避免只写“高级”“好看”等抽象词。

合格示例：

- 延续：产品主体占画面约三分之一，标题与主体形成明确左右分区。
- 避免：三个以上卖点使用相同字号，导致主次不清。

### 周四：黄金样本评审

- 每条业务线从已确认案例中选出真正能指导未来工作的样本。
- 公司推荐必须由设计总监或业务负责人确认。
- 长期目标是建立 30～50 个黄金项目，而不是只积累零散图片。
- 黄金项目需覆盖不同渠道、营销阶段和关键业务目标。

### 周五：真实业务验证

- 在设计服务页输入真实业务线、渠道、营销阶段、目标和需求。
- 生成结果只能作为方向建议，仍需设计师完成专业判断。
- 项目结束后必须回填：采用、需要修改或拒绝，并说明原因。
- 每周复盘“系统建议—最终设计—业务结果”的差异。

## 黄金项目建议结构

30～50 个黄金项目可按以下方式建立：

- 每条业务线 6～10 个项目。
- 每个项目保留需求背景、最终成品、关键版本和业务结果。
- 至少覆盖新品首发、活动预热、核心卖点、对比教育和品牌信任。
- 每个项目选 3～8 张真正有训练价值的代表素材。
- 不把同一模板的大量换图版本计为多个黄金项目。

## 月度清理

- 删除或降权已经过时的风格规则。
- 检查“公司推荐”是否仍适合当前品牌和渠道。
- 找出经常被拒绝的生成方向，补充避坑规则。
- 找出高采用方向，补充为黄金项目或公司推荐样本。
- 检查五条业务线是否存在样本失衡。

## 判断系统是否真正训练好

必须同时满足：

1. 五条业务线都达到正式使用门槛。
2. 画像中的延续规则和避坑规则来自人工明确判断。
3. 设计服务能显示所引用的公司证据。
4. 每次真实服务都能回填最终结果。
5. 连续一个月的采用率和修改原因有可复盘记录。

在满足以上条件前，系统仍处于训练或试运行阶段。
